# YipProductApp

A mobile app built with **React Native** and **Expo** that allows users to upload up to 5 products.

---

## Overview
YipProductApp is a mobile application designed for a simple product management workflow. Users can:
- Upload up to 5 products.
- Input product name, photo and price.
- Receive notifications when the product limit is reached.

The app focuses on **clean UI**, **smooth UX** and uses **local state management** to manage product data.

---

## Features
- Upload multiple products (up to 5)
- Store product details (name, photo, price)
- Notifications when the product limit is reached
- Clean and responsive UI
- Uses **local state management** (Redux API)

---

## Tech Stack
- **React Native** 
- **Expo**
- **TyperScript**
- **Redux API** 
- **React Navigation**

## Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/MisturaDev/YipProductApp.git

2. Navigate into the project folder:
    ```bash
    cd YipProductApp

3. Install dependencies.:
    ```bash
    npm install

4. Run the app (Expo):
   ```bash
   npx expo start


5. Open on your device using Expo Go or Dev Client

6. Configure Firebase:
   - Create a Firebase project
   - Copy your config into firebase.ts


---

## Usage

- Open the app.

- Tap the Add Product button.

- Enter name, select photo, and input price.

- Repeat up to 5 products.

- Once the limit is reached, a notification appears.
